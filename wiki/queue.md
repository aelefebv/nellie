# Queue — open architectural questions

Unresolved decisions, design questions, or known unknowns surfaced by the wiki seeding pass. Add items as they arise; remove them when resolved (with a pointer to the decision article or commit that resolved them).

## Open

- **macOS hard-pinned to CPU** in `nellie/__init__.py` — the MPS branch is commented out. Will Apple Silicon GPU support be revived? See [[gpu-runtime]].
- **`SettingsConfig` round-trip in the [[settings|napari settings widget]] is dead code today** — preset save/load not wired. Ship or remove?
- **Hu-moment cost weighting is unjustified in code** — z-scored sum of distance + stats + Hu blocks with no learned weights or rationale committed. Document the heuristic or replace? See [[hu-tracking]].
- **`flow_interpolation.py __main__` block has a `self.im_info` typo bug** — uses `self` outside a class. Remove or fix. See [[flow-interpolation]].
- **Plugin-menu injection touches napari private API** (`viewer.window._qt_window` + literal `"&Plugins"` string). Will silently break on napari ≥ 0.5 menu changes. See [[napari-plugin/index|napari plugin]] and [[loader]].
- **`Hierarchy.skip_nodes` defaults differ between callers.** [[pipeline|`run.py`]] hard-codes `False`; the [[settings|napari settings widget]] exposes it as a flag. Reconcile?
- **OOM detection in `adaptive_run` string-sniffs `"out of memory"`.** Fragile across CuPy/CUDA driver versions — new error wordings silently break the fallback. See [[gpu-runtime]].
- **Verifier (`im_info/verifier.py`) is unpinned by tests.** The legacy `test_verifier_metadata.py` was wiped during the May 2026 scaffold rebuild and not restored. The dechaos report at [[outputs/dechaos-verifier|`wiki/outputs/dechaos-verifier.md`]] (Pass 7) lists the full contract surface: per-format `dim_res` parsing (OME, ImageJ, ImageJ-fallback to TIFF tags, raw TIFF tag unit conversion incl. all 3 RESUNIT cases), `_normalize_time_axis` leading-singleton heuristic, the half-commented `change_axes` gate (intentional UX hack — gate disabled at verifier level because napari fileselect widget pre-validates length; Slice 1 pins current behavior), `_validate`'s asymmetric raise (intentional design — programmer errors raise, user-input errors flag), `_normalize_axes` vs `_axis_errors` allowed-set divergence on `C` (intentional contract — FileInfo accepts multichannel input, save_ome_tiff collapses C, ImInfo only ever reads post-collapse files), `change_dim_res` / `change_selected_channel` / `select_temporal_range` validation contracts, `save_ome_tiff` channel-collapse + T-slicing, OME provenance JSON round-trip, `ImInfo._normalize_axes` / `_normalize_memmap` Z-squeeze, `ImInfo` auto-regen-on-construction behavior, `pipeline_paths` 18-key surface. ~50–80 characterization tests. Per-format fixtures generated programmatically via `tests/fixtures/_generate.py` (OME-TIFF + ImageJ-with-physicalsize + ImageJ-without-physicalsize + raw-TIFF × 3 RESUNIT cases). **ND2 deferred** — see follow-up below. See [[im-info]] and the dechaos report's Slice 1 in Pass 8. **This slice unblocks Slice 2+ (clarify, constructor-I/O extraction, unified normalizer, validation split, extractor strategy).**
- **ND2 characterization tests deferred** (sub-task of the verifier test-pinning slice above). The `nd2` library is read-only — no programmatic ND2 generation. No ND2 sample currently checked in. Two paths: (a) source a tiny single-frame `.nd2` and check it into `tests/fixtures/` (then add fixture-driven tests for `_get_nd2_metadata` covering `volume.axesCalibration` + `channels[0].volume.axesCalibration` fallback + `Time [s]` median-of-diffs + single-timepoint `T=None`); (b) skip ND2 tests entirely until the bioio integration (queued separately) renders the per-format ND2 path obsolete. **Eligible** when an ND2 sample becomes available OR after bioio integration lands.
- **Cross-stage Config validation pass** — add lightweight `__post_init__` checks to all 7 Configs ([[filtering|`FrangiConfig`]], `LabelConfig`, `NetworkConfig`, `MarkersConfig`, `HuMomentTrackingConfig`, `VoxelReassignerConfig`, `HierarchyConfig`) for the obvious cases (string-set membership for `device` / `mode`, non-negative numerics, ordered `min_radius_um <= max_radius_um` ranges). Eligible immediately. Each Config's validation is independent; could land as one PR or per-stage micro-PRs. Pinned by existing characterization tests (no behavior change at default values). Deferred from PRD #112 per resolved decision #4.
- **Napari widget Config-return typing pass** — switch all 7 `get_*_params` methods in `nellie_napari/nellie_settings.py` to return Config objects directly (including [[filtering|`Filter`]] retrofit). The processor's `_run_*` methods become one-liners. Imports each stage's Config class into the napari widget module. Eligible immediately. Deferred from PRD #112 per resolved decision #5.
- **Broaden file-format support via `bioio`.** Today the verifier (`nellie/im_info/verifier.py`) hard-dispatches on extension into `_find_tif_metadata` / `_find_nd2_metadata` (5 `metadata_type` branches: `'ome'`, `'imagej'`, `'imagej_tif_tags'`, `'nd2'`, `None`). Adding new formats (CZI, LIF, LSM, etc.) currently means hand-writing a new branch + a new `_get_*_metadata` extractor. `bioio` (https://github.com/bioio-devs/bioio) and its plugin ecosystem (`bioio-czi`, `bioio-lif`, `bioio-bioformats`, etc.) wrap most microscopy formats behind a single `BioImage(path)` API with a normalized `physical_pixel_sizes` + axes/shape/dtype interface. Migration path: introduce a `BioioExtractor` after Slice 6's `MetadataExtractor` strategy seam lands (per [[outputs/dechaos-verifier|verifier dechaos]] Pass 8), which subsumes most existing extractors and adds CZI/LIF/etc. for free. Trade-off: adds `bioio` (+ format plugins) to dependencies; some formats need optional installs (`bioio-bioformats` requires Java); `bioio`'s `physical_pixel_sizes` is in micrometers (matches our `dim_res`) but axes/dim ordering may need translation. **Do not start before** the verifier dechaos refactor's Slice 6 (extractor strategy) lands — `bioio` integration is much cleaner once the strategy seam exists.
